Overview

This vignette demonstrates how to use flowUtilities to simplify flow cytometry data analysis workflows. The package makes use of the Bioconductor libraries flowCore, flowWorkspace, and flowStats to streamline data import, gating, visualization, and statistical analysis.

Load data and apply compensation

The example data is from human postnatal thymus that were stained with CD3, CD4, CD8a, CD27, CCR7, and TCRαβ antibodies. It includes two samples and six fluorescent-minus-one controls. We can read the .fcs files into a flowWorkspace::cytoset object.

library(flowWorkspace)
library(flowCore)
library(flowUtilities)

dir <- system.file("extdata", package="flowUtilities")
files <- list.files(dir, pattern = ".fcs",full.names = TRUE)

# Load cytoset
cs <- load_cytoset_from_fcs (files)
cs

The compensation was calculated with the cytometer software and the spill matrices stored in the .fcs files. We can use apply_compensation_from_fcs to find them and apply compensation to the data.

cs <- apply_compensation_from_fcs(cs)

The channel names used by the cytometer have the format “FLn-A”, “FLn-H” recording the area and height, respectively. We don’t need the height channels and can remove them using filter_channels. Again, we’ll use a regular expression to exclude all channels using the pattern “FL” followed by one or more digits “\\d+” then “-H”.

cs <- filter_channels(cs, exclude="FL\\d+-H")

Adding metadata from filenames

This data was collected using a CytoFlex LX cytometer. The resultant .fcs file names have the format “01-MySample-A1.fcs”, where “01” is the plate ID, “MySample” is the sample ID, and “A1” is the well (or tube) ID. In this example, the sample ID includes details to identify the type (sample or FMO control) that will be useful later.

We can extract all of this metadata from the file names using regular expressions and add it to the phenoData contained in the GatingSet object. This will allow us to select samples or groups of samples for plotting or further analysis.

Provide any number of named arguments to read_filenames_to_pdata with regular expression patterns to search for. The names will be added as columns to phenoData with the search results as column entries. Here we are adding the sample, group, and fmo metadata.

cs <- read_names_to_pdata(cs,
                          sample = "(?<=\\d{2}-)(.+?)(?=(-[A-Z]{1}\\d{1,2}.fcs))",
                          group = "(?i)fmo|sample",
                          fmo = "CD\\d+[A-z]*|TCR[A-z]{2}|CCR7|ZOMBIE-UV")

Adding informative marker names

The .fcs files contain user-defined marker names (like “CD3”, “CD4”, etc.) that we would like to use instead of “FLn-A”. These marker names also include other details like the laser and filter set that we don’t need. Calling get_marker_names with the appropriate regular expression will extract the useful marker names while ignoring the rest. Channels that were recorded but did not include an antibody will be labeled with the default “UNUSED”.

markers <- get_marker_names(cs,
                            "CD\\d+[A-z]*|TCR[A-z]{2}|CCR7|ZOMBIE-UV",
                            default_name = "UNUSED")

If we’re happy with the marker names, we can make them the new channel names.

cs <- set_channels_from_markers(cs, markers = markers)

Transforming fluorescent channels

To improve data visualization, we can apply a logicle transformation to fluorescent channels. The estimateLogicleTransform function estimates reasonable parameters for the data and returns a transformerList to apply to our data. First, we’ll create a flowWorkspace::GatingSet object to store our transformation and subsequent gates.

# Make GatingSet
gs <- GatingSet(cs)

# What to transform
markers <- c("CCR7", "CD27", "CD3", "CD4", "CD8a", "TCRab", "ZOMBIE-UV")

# Estimate logicle parameters
transList <- estimateLogicleTransform(gs, channels = markers, m=5)
# Apply transformation to GatingSet
gs <- transform(gs, transList)

We can visualize the transformation using plot_stacked_hist. We don’t need to plot all of the data, so we’ll use get_samples_by_keyword to select only the FMO controls using the phenoData group ID that we added previously.

# Retrieve fmos for visualization
gs_fmo <- get_samples_by_keyword(gs, group="FMO")
# Plot
plot_stacked_hist(gs_fmo, markers, nrow = 1)

Building the gating hierarchy

Gating data involves constructing gate objects and sequentially applying them to the GatingSet (see the flowWorkspace vignette for an introduction).

Boundary filter

Often there are events at or near the detection limit of the cytometer that are uninformative and make setting plot limits a pain. We can apply a flowCore::rectangleGate to the FSC-A and SSC-A channels to clean up the data. The plot_grid function can be used to visualize the gate.

parentID <- "root"
gateID <- "BoundaryFilter"

x_axis <- "FSC-A"
y_axis <- "SSC-A"

# Define gate edges
edges <- list(c(0, 1.0e6),   # FSC-A
              c(0, 0.3e6))   # SSC-A
names(edges) <- c(x_axis, y_axis)

# Create rectangle gate
gate <- flowCore::rectangleGate(edges, filterId = gateID)

# Visualize gate
plot_grid(gs_fmo,
          x_axis,
          y_axis,
          gate,
          limits = edges,
          subset = parentID,
          facet_by = "sample",
          ncol = 3,
          n_bins = 2048)

Singlet discrimination

Single cells can be gated by applying a flowCore::polygonGate to events along the diagonal of the FCS-A by FSC-H channels. This process can be automated by applying a robust linear model to detect single cells in each sample in the GatingSet. The singletsGates function does this and returns a list of gates (one for each sample). We can visualize the gate before applying it.

parentID <- "BoundaryFilter"
gateID <- "Singlets"

x_axis <- "FSC-A"
y_axis <- "FSC-H"

# Estimate singlet gates per sample using RLM
gate <- autoSingletGate(gs,
                      area = x_axis,
                      height = y_axis,
                      parentId = parentID,
                      gateId = gateID)

# Visualize gate
plot_grid(gs_fmo,
          x_axis,
          y_axis,
          gate,
          limits = "data",
          subset = parentID,
          facet_by = "sample",
          ncol = 3)

Apply the gate.

gs_pop_add(gs, gate, parent=parentID)
#> [1] 3
recompute(gs)

Identify lymphocytes

Lymphocytes can be identified based on their FSC-A and SSC-A characteristics. The function lymphocyteGate can automate this process. Because many of these cells are CD3+, we can use the CD3 channel to improve lymphocyte detection.

parentID <- "Singlets"
gateID <- "Lymphocytes"

x_axis <- "FSC-A"
y_axis <- "SSC-A"

# Define lymphocyte gate using CD3 preselection
gate <- autoLymphGate(gs,
                      x = x_axis,
                      y = y_axis,
                      preselection = "CD3",
                      parentId = parentID,
                      gateId = gateID)

# Visualize gate
plot_grid(gs_fmo,
          x_axis,
          y_axis,
          gate,
          limits="data",
          subset=parentID,
          facet_by="sample",
          ncol=3)

gs_pop_add(gs, gate, parent=parentID)
#> [1] 4
recompute(gs)

Viable cell selection

Use a flowCore::rectangleGate to exclude dead cells using the Zombie-UV viability dye.

parentID <- "Lymphocytes"
gateID <- "Live"

x_axis <- "ZOMBIE-UV"
y_axis <- "SSC-A"

# Define rectangle gate for live cells
edges <- list(c(-0.8, 0.8),
              c(0, 1.5e5))
names(edges) <- c(x_axis, y_axis)

gate <- flowCore::rectangleGate(edges, filterId=gateID)

# Visualize gate
plot_grid(gs_fmo,
          x_axis,
          y_axis,
          gate,
          limits="data",
          subset=parentID,
          facet_by="sample",
          ncol=3)

# Apply gate
gs_pop_add(gs, gate, parent=parentID)
#> [1] 5
recompute(gs)

Identifying T Cells

We can gate T cells based on expression of CD3 and TCRαβ. diagPolygonGate is a convenience function for constructing a gate along a diagonal population (it can also be used for singlet discrimination).

parentID <- "Live"
gateID <- "CD3+TCRab+"

x_axis <- "CD3"
y_axis <- "TCRab"

# Define diagonal polygon gate
gate <- diagPolygonGate(x = x_axis,
                        y = y_axis,
                        width = 2.2,
                        height = 2.2,
                        origin = c(1.15, 1.0),
                        diag_width = 0.75,
                        gateId = gateID)

# Visualize gate
plot_grid(gs_fmo,
          x_axis,
          y_axis,
          gate,
          limits=list(x=c(0, 4.2), y=c(0, 4)),
          subset=parentID,
          facet_by="sample",
          ncol=3)

# Apply gate
gs_pop_add(gs, gate, parent=parentID)
#> [1] 6
recompute(gs)

Gate CD4 and CD8 T cell subsets

We can identify CD4+CD8+ (DP), CD4+CD8- (4SP), and CD4-CD8+ (8SP) T cell populations. The “fmo” column in phenoData contains marker names that match the FMO controls to their respective channel. The autoQuadGate function can use this information to set threshold of a quadrant gate. It calculates the quantile using each channel’s FMO based on the probs argument. The function returns a list containing a flowCore::quadGate object and a vector of names to apply to each quadrant population.

parentID <- "CD3+TCRab+"
gateID <- "CD4/CD8"

x_axis <- "CD4"
y_axis <- "CD8a"

# Define quadrant gates using FMO controls
gate <- autoQuadGate(gs,
                     x = x_axis,
                     y = y_axis,
                     probs = 0.99,
                     ctrlId = "fmo",
                     parentId = parentID,
                     gateId = gateID)
#> $CD4
#> [1] 0.6884761
#> 
#> $CD8a
#> [1] 1.576837

# Visualize gate
plot_grid(gs_fmo,
          x_axis,
          y_axis,
          gate$gate,
          limits="data",
          subset=parentID,
          facet_by="sample",
          ncol=3)

# Apply gate
gs_pop_add(gs, gate$gate, parent=parentID, names=gate$names)
#> [1]  7  8  9 10
recompute(gs)

Plot the gating hierarchy for samples

After gating, we can visualize the gating hierarchy using plot_gating_hierarchy. This function is intended to save the plots in a directory rather than print to screen. However, we can return the plots to display for a small number of samples.

# Select samples to plot
gs_samp <- get_samples_by_keyword(gs, group="SAMPLE")
#> 2 samples found:
#> 01-SAMPLE_A-A4.fcs
#> 01-SAMPLE_B-A5.fcs
# Plot gating hierarchy
plot_gating_hierarchy(gs_samp,
                      output_dir = NULL,
                      ncol = 3, 
                      width = 5, 
                      height = 8,
                      limits = "data",
                      remove_axis_ticks = TRUE,
                      top_margin = 0.25,
                      return_plots = TRUE)
